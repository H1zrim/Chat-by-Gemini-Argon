# RT-Ku (v0.1 — Vanilla Client-Side Prototype)

Dokumentasi rilis sementara **v0.1** untuk prototipe awal aplikasi komunitas & komunikasi warga **RT-Ku**.

## Cakupan v0.1
- **Stack**: HTML5, Vanilla CSS3, Vanilla JavaScript (`localStorage` persistence).
- **Fitur Utama**:
  1. Autentikasi & Registrasi warga berbasis NIK (16 digit) dan kata sandi.
  2. Tampilan 2-Kolom (Sidebar kontak/grup RT & Area Obrolan real-time simulasi).
  3. Panel Admin RT (CRUD pembersihan data fiktif, verifikasi status warga `Active`, `Pending`, `Fictional`).

> Lihat branch **`development`** untuk arsitektur terbaru yang mengadopsi pola desain dari repositori open-source bintang lima (Mattermost, Rocket.Chat, Zulip, HumHub/Meta Workplace).
